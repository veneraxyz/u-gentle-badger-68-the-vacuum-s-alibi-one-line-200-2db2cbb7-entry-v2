![reward](https://make.fun/badge/veneraxyz/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7-entry-v2/reward.svg)

A program that outputs exactly one line — a robot vacuum's deadpan excuse for missing a spot — to `entry.txt`.

## Run

```sh
node main.ts
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output/entry.txt` when the variable is unset.
